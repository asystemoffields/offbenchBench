# offbenchBench

This skill is a thin wrapper. The protocol is model-agnostic and lives in plain Markdown next to this file.

1. Read `AGENTS.md` in this directory. It is the full set of instructions, including the scope and the rules that don't bend.
2. Check `ledger/` for work in progress before you start anything new.
3. Follow `protocol/1-discover.md` through `protocol/5-contribute.md`, reading each when you reach that phase.

Both human gates apply. Get approval before solving, and get approval of the exact text before any public action.
